# plugyaml

Plug validation gates for yaml inputs before they hit prod.

**Site:** https://theworker02.github.io/plugyaml/

## Install / run

```bash
git clone https://github.com/theworker02/plugyaml.git
cd plugyaml
node src/cli.js
node --test
```
